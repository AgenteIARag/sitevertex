# Vertex Consórcios - Veículos Pesados 🚛🚜🚐

Landing page moderna e responsiva da **Vertex Consórcios**, voltada para aquisição e renovação de frotas de veículos pesados (caminhões, tratores e furgões/utilitários) sem juros.

---

## 🚀 Funcionalidades

- **Simulador Inteligente em Tempo Real:**
  - Seleção por categoria (Caminhão, Trator, Utilitário).
  - Controle deslizante para valor de crédito (R$ 100 mil a R$ 3 milhões).
  - Opções de prazos de 12 a 120 meses.
  - Lance/entrada dedutível com cálculo automático das parcelas mensais, taxa de administração e fundo de reserva.
- **Integração com WhatsApp:**
  - Envio instantâneo dos dados da simulação estruturados diretamente para o atendimento no WhatsApp.
- **Design Totalmente Responsivo:**
  - Layout otimizado para celulares, tablets e desktops.
  - Carrossel infinito de fotos reais dos veículos.
  - Botão flutuante de atendimento para dispositivos móveis.
- **Seção de FAQ e Diferenciais:**
  - Accordion dinâmico para dúvidas frequentes.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**
- **CSS3 Moderno** (Flexbox, CSS Grid, variáveis e animações)
- **Vanilla JavaScript** (Sem dependências pesadas, carregamento ultra-rápido)
- **Google Fonts** (Montserrat)
